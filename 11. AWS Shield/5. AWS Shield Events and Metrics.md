AWS Shield Event and Metrics

Before proceeding, let's review another critical aspect of AWS Shield. Global activity encompasses Distributed Denial of Service (DDoS) events observed across the entire spectrum of AWS customers. AWS updates this information once per hour, providing a retrospective analysis for the preceding two weeks. Within the console pane, users can visualize these insights, categorized by AWS Region and illustrated on a world heat map. Adjacent to the map, AWS Shield presents a summary that includes details such as the most substantial packet attack, highest bit rate, prevalent attack vector, overall attack count, and the threat level. The threat level gauges the current global activity against AWS's typical observations, with the default threat level set at Normal. AWS dynamically adjusts this value to High in the presence of heightened DDoS activity.

The Global Threat Dashboard extends its utility by offering time-series metrics and allowing users to switch between different time durations. For a historical perspective on noteworthy DDoS attacks, users can personalize the dashboard to display data ranging from the last day to the last two weeks. Time-series metrics furnish a comprehensive view of the largest bit rate, packet rate, or request rate for all events detected by AWS Shield, providing valuable insights into the security landscape for applications hosted on AWS during the selected time window.

AWS Shield Advanced Events
Upon subscribing to AWS Shield Advanced and securing your resources, you unlock enhanced visibility features for those resources. These features include timely notifications of events identified by Shield Advanced, along with supplementary details regarding the detected events and applied mitigations.

AWS Shield conducts a thorough evaluation of traffic directed toward your protected resource across various dimensions. Upon detecting an anomaly, Shield Advanced generates distinct events for each impacted resource.

For comprehensive access to event summaries and intricate details, users can navigate to the Events page within the Shield console. The primary Events page offers a comprehensive overview of both ongoing and past events.

AWS Shield Advanced Metrics
Shield Advanced publishes Amazon CloudWatch event metrics for all protected resources, enhancing your resource monitoring capabilities. These metrics empower you to establish and configure CloudWatch dashboards and alarms, enabling proactive response to potential threats.

Shield Advanced Amazon CloudWatch Metrics
DDoSDetected : Indicates the presence of a DDoS event for a specific Amazon Resource Name (ARN). The metric registers a value of 1 during an event and 0 otherwise.
DDoSAttackBitsPerSecond : Reflects the volume of bytes observed during a DDoS event for a specific ARN. This metric is exclusive to network and transport layer (Layer 3 or 4) DDoS events, with the unit measured in bits.
DDoSAttackPacketsPerSecond : Denotes the number of packets observed during a DDoS event for a specific ARN. Similar to the previous metric, this applies to network and transport layer (Layer 3 or 4) DDoS events, with the unit measured in packets.
DDoSAttackRequestsPersecond : Represents the count of requests observed during a DDoS event for a specific ARN. This metric is specific to application layer (Layer 7) DDoS events, with the unit measured in requests.

If there are no events to report to a CloudWatch metric, Shield Advanced publishes a zero-value metric once per day. This practice ensures that the metric remains active and available for integration into custom CloudWatch alarms and dashboards.

1. Global Threat Dashboard (Aktivitas Global DDoS)
    Global activity mencakup DDoS events yang diamati di seluruh spektrum pelanggan AWS.
    AWS memperbarui informasi ini setiap satu jam sekali, menyediakan analisis retrospektif untuk dua minggu sebelumnya.
    Di dalam konsol, pengguna dapat memvisualisasikan wawasan ini yang dikategorikan berdasarkan AWS Region dan diilustrasikan pada world heat map.
    Di samping peta, AWS Shield menyajikan ringkasan yang mencakup:
        Most substantial packet attack
        Highest bit rate
        Prevalent attack vector
        Overall attack count
        Threat level

Threat Level:
    Mengukur aktivitas global saat ini terhadap pengamatan tipikal AWS.
    Default threat level: Normal.
    AWS secara dinamis menyesuaikan nilai ini menjadi High ketika ada peningkatan aktivitas DDoS.

Fitur Tambahan:
    Global Threat Dashboard menawarkan time-series metrics dan memungkinkan pengguna beralih antara durasi waktu yang berbeda.
    Untuk perspektif historis tentang serangan DDoS yang signifikan, pengguna dapat menyesuaikan dashboard untuk menampilkan data dari hari terakhir hingga dua minggu terakhir.
    Time-series metrics memberikan tampilan komprehensif tentang bit rate, packet rate, atau request rate terbesar untuk semua event yang terdeteksi oleh AWS Shield.

2. AWS Shield Advanced Events
    Setelah berlangganan Shield Advanced dan mengamankan resource Anda, Anda membuka enhanced visibility features untuk resource tersebut.
    Fitur ini mencakup:
        Timely notifications (notifikasi tepat waktu) dari event yang diidentifikasi oleh Shield Advanced.
        Detail tambahan mengenai event yang terdeteksi dan mitigasi yang diterapkan.

Cara Kerja Deteksi:
    Shield Advanced melakukan evaluasi menyeluruh terhadap lalu lintas yang diarahkan ke resource yang dilindungi di berbagai dimensi.
    Setelah mendeteksi anomali, Shield Advanced menghasilkan event yang berbeda untuk setiap resource yang terkena dampak.

Akses Event:
    Untuk akses komprehensif ke ringkasan event dan detail yang rumit, pengguna dapat navigasi ke halaman Events di konsol Shield.
    Halaman Events utama menawarkan gambaran komprehensif tentang ongoing dan past events.

Mitigasi Otomatis:
    Shield Advanced dapat secara otomatis (autonomously) menerapkan mitigasi sebagai respons terhadap serangan, tergantung pada pola lalu lintas dan safeguards yang dikonfigurasi.
    Mitigasi ini berfungsi untuk melindungi resource dari lalu lintas berlebihan atau pola lalu lintas yang sesuai dengan tanda tangan serangan DDoS yang dikenal.

3. AWS Shield Advanced Metrics (CloudWatch Metrics)
Shield Advanced mempublikasikan CloudWatch event metrics untuk semua resource yang dilindungi, meningkatkan kemampuan monitoring resource. Metrik ini memungkinkan Anda untuk menyiapkan dan mengonfigurasi CloudWatch dashboards dan alarms untuk respons proaktif terhadap potensi ancaman.

Empat Metrik Utama Shield Advanced:
a. DDoSDetected
    Menunjukkan keberadaan DDoS event untuk Amazon Resource Name (ARN) spesifik.
    Metrik mencatat nilai 1 selama event berlangsung dan 0 jika tidak.

b. DDoSAttackBitsPerSecond
    Mencerminkan volume byte yang diamati selama DDoS event untuk ARN spesifik.
    Eksklusif untuk network dan transport layer (Layer 3 atau 4) DDoS events.
    Satuan: bits

c. DDoSAttackPacketsPerSecond
    Menunjukkan jumlah paket yang diamati selama DDoS event untuk ARN spesifik.
    Berlaku untuk network dan transport layer (Layer 3 atau 4) DDoS events.
    Satuan: packets

d. DDoSAttackRequestsPerSecond
    Mencerminkan jumlah request yang diamati selama DDoS event untuk ARN spesifik.
    Spesifik untuk application layer (Layer 7) DDoS events.
    Satuan: requests

Catatan Penting:
    Jika tidak ada event untuk dilaporkan ke CloudWatch metric, Shield Advanced mempublikasikan zero-value metric sekali per hari.
    Praktik ini memastikan metrik tetap aktif dan tersedia untuk integrasi ke dalam CloudWatch alarms dan dashboard kustom.
