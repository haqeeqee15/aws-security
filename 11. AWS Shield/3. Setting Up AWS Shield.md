Setting up AWS Shield
AWS Shield is a managed service designed to defend applications on AWS against Distributed Denial of Service (DDoS) attacks. AWS Shield Standard is automatically enabled for all AWS customers at no additional cost while AWS Shield Advanced is an optional paid service that provides additional protection against more complex and larger attacks for your applications running on Amazon Elastic Compute Cloud (EC2), Elastic Load Balancing (ELB), Amazon CloudFront, AWS Global Accelerator, and Route 53.

So you don’t need to take any action to set up the AWS Shield Standard version. But for the advanced version, you need to subscribe and it costs $3000 per month.

How to subscribe to AWS Shield Advanced
Subscribing to AWS Shield Advanced involves a few steps :

Decision and Preparation
Evaluate your needs : Assess your DDoS risk and determine whether Shield Advanced's enhanced protection suits your requirements. Consider the complexity of your applications, potential attack targets, and the financial impact of downtime.

Review pricing : Review the subscription fee and data transfer usage charges. ($3000 / Monthly)

Gather resources : You'll need IAM permissions to enable Shield Advanced and manage protected resources. Ensure you have access to the AWS Management Console and the AWS CLI.

Subscription Process

1. Access the AWS Management Console : Navigate to the Shield section.
![1](https://ld-images-2.s3.us-east-2.amazonaws.com/AWS+Shield/3.Setting+up+AWS+Shield/image3_1.png)
![2](https://ld-images-2.s3.us-east-2.amazonaws.com/AWS+Shield/3.Setting+up+AWS+Shield/image3_2.png)
2. Create a subscription : Click "Subscribe to Shield Advanced".
![3](https://ld-images-2.s3.us-east-2.amazonaws.com/AWS+Shield/3.Setting+up+AWS+Shield/image3_3.png)
3. Acknowledge service terms :
    Pricing : $3000 / month subscription fee for a consolidated billing family.
    Pricing : Data transfer out usage fees for all protected resources.
    Commitment : I am committing to a 12-month subscription.
    Auto-renewal : Subscription will be auto-renewed after 12 months. However, I can opt out of renewal 30 days prior to the renewal date.
Important : Once you have subscribed to this service, the only way to unsubscribe is by contacting the support team.

Post-Subscription Steps
1. Protect resources : Add your desired resources like EC2 instances, Elastic Load Balancers, CloudFront distributions, etc., to your AWS Shield Advanced subscription for protection.
2. Configure protections : Tailor application-layer and health-based detections to your specific needs.
3. Set up SRT contact : If you opted for Proactive Engagement, provide contact information for your security and technical teams.
4. Monitoring and notifications : Set up CloudWatch dashboards and alarms to monitor attack activity and receive alerts.

Subscribing to AWS Shield Advanced is a significant decision with associated costs. It's crucial to thoroughly evaluate your needs and configure the service correctly for optimal protection. 

1. Pengenalan AWS Shield
    AWS Shield adalah layanan terkelola yang dirancang untuk mempertahankan aplikasi di AWS terhadap serangan DDoS.
    AWS Shield Standard diaktifkan secara otomatis untuk semua pelanggan AWS tanpa biaya tambahan.
    AWS Shield Advanced adalah layanan berbayar opsional yang memberikan perlindungan tambahan terhadap serangan yang lebih kompleks dan lebih besar untuk aplikasi yang berjalan di EC2, ELB, CloudFront, AWS Global Accelerator, dan Route 53.

Catatan Penting:
    Untuk versi Standard, Anda tidak perlu mengambil tindakan apa pun.
    Untuk versi Advanced, Anda perlu berlangganan dengan biaya $3000 per bulan.

2. Cara Berlangganan AWS Shield Advanced
A. Tahap Decision and Preparation
    Evaluate your needs: Nilai risiko DDoS Anda dan tentukan apakah perlindungan tambahan Shield Advanced sesuai dengan kebutuhan Anda. Pertimbangkan kompleksitas aplikasi, potensi target serangan, dan dampak finansial dari downtime.
    Review pricing: Tinjau biaya langganan ($3000 per bulan) dan biaya penggunaan data transfer.
    Gather resources: Anda memerlukan izin IAM untuk mengaktifkan Shield Advanced dan mengelola resource yang dilindungi. Pastikan Anda memiliki akses ke AWS Management Console dan AWS CLI.

B. Subscription Process
    Access the AWS Management Console → Navigasi ke bagian Shield.
    Create a subscription → Klik "Subscribe to Shield Advanced".
    Acknowledge service terms:
        Pricing: $3000 per bulan untuk consolidated billing family.
        Pricing: Biaya penggunaan data transfer out untuk semua resource yang dilindungi.
        Commitment: Komitmen untuk berlangganan 12 bulan.
        Auto-renewal: Langganan akan diperpanjang secara otomatis setelah 12 bulan. Namun, Anda dapat memilih untuk tidak memperpanjang (opt out) 30 hari sebelum tanggal perpanjangan.

Peringatan Penting:
    Setelah Anda berlangganan layanan ini, satu-satunya cara untuk berhenti berlangganan (unsubscribe) adalah dengan menghubungi tim dukungan (support team).

C. Post-Subscription Steps
    Protect resources → Tambahkan resource yang diinginkan (EC2 instances, Elastic Load Balancers, CloudFront distributions, dll.) ke langganan Shield Advanced Anda untuk perlindungan.
    Configure protections → Sesuaikan application-layer dan health-based detections sesuai kebutuhan spesifik Anda.
    Set up SRT contact → Jika Anda memilih Proactive Engagement, berikan informasi kontak untuk tim keamanan dan teknis Anda.
    Monitoring and notifications → Atur CloudWatch dashboards dan alarms untuk memantau aktivitas serangan dan menerima peringatan.
