Best Practices for AWS WAF

Rule Optimization for Effective Protection Without Blocking Legitimate Traffic

Regularly Review Rules
    Periodically review all rules within your Web ACLs to ensure they are still relevant to your application's security needs.
    Remove outdated rules that are no longer necessary or effective in protecting against current threats.

Implement Specific Rules
    Create specific rules tailored to your application's behavior and legitimate traffic patterns.
    Avoid broad rules that might inadvertently block legitimate requests. Instead, craft rules that target specific malicious patterns.

Use Whitelists
    Implement whitelists for IP addresses, user agents, or other legitimate traffic sources to ensure they are never blocked.
    Whitelists are particularly useful for internal services, known partners, or trusted third-party applications interacting with your system.


Monitoring and Logging for WAF

Set Up CloudWatch Alarms
    Configure Amazon CloudWatch alarms to monitor key metrics such as blocked requests, allowed requests and rule match counts.
    Set thresholds to receive notifications when unusual traffic patterns or a high number of rule matches occur.

Enable AWS WAF Logging
    Enable AWS WAF logging to capture detailed information about web requests, rule matches, and actions taken.
    Store logs in Amazon S3 buckets and use AWS services like Amazon Athena or Amazon QuickSight for in-depth analysis and reporting.

Regularly Review Logs
    Regularly review AWS WAF logs to identify potential attacks, false positives, or evolving patterns of malicious traffic.
    Investigate any anomalies in the logs promptly to ensure that new threats are detected and mitigated on time.


Regularly Updating and Fine-Tuning WAF Rules

Stay Informed
    Stay updated with the latest security threats and vulnerabilities relevant to your application stack.
    AWS provides security bulletins and updates; subscribe to them to remain informed about new attack vectors.

Test Rule Changes
    Before applying rule changes to production, test them in a staging environment to ensure they don't inadvertently block legitimate traffic.
    Use tools like AWS WAF's web ACL simulator to understand the impact of rule changes on your traffic.


Schedule Regular Reviews
    Schedule regular reviews of your AWS WAF configuration, at least quarterly, to assess its effectiveness against current threats.
    Update rules, conditions, and web ACLs based on the insights gathered from monitoring, logging, and ongoing threat intelligence.


By adhering to these best practices, blue team members can maintain a strong security posture, ensuring that AWS WAF is optimized to protect against threats while allowing legitimate traffic to flow smoothly to your web applications. Regular monitoring, proactive rule optimization, and staying up-to-date with the evolving threat landscape are key to a robust web security strategy. 

1. Rule Optimization untuk Perlindungan Efektif Tanpa Memblokir Lalu Lintas Sah
a. Tinjau Aturan Secara Berkala
    Tinjau semua aturan dalam Web ACL secara periodik untuk memastikan masih relevan dengan kebutuhan keamanan aplikasi.
    Hapus aturan usang yang tidak lagi diperlukan atau tidak efektif dalam melindungi dari ancaman saat ini.

b. Terapkan Aturan yang Spesifik
    Buat aturan spesifik yang disesuaikan dengan perilaku aplikasi dan pola lalu lintas sah.
    Hindari aturan yang terlalu luas karena dapat secara tidak sengaja memblokir request yang sah. Sebaliknya, buat aturan yang menargetkan pola berbahaya spesifik.

c. Gunakan Daftar Putih (Whitelists)
    Terapkan whitelist untuk alamat IP, user agents, atau sumber lalu lintas sah lainnya untuk memastikan mereka tidak pernah diblokir.
    Whitelist sangat berguna untuk layanan internal, mitra yang dikenal, atau aplikasi pihak ketiga tepercaya yang berinteraksi dengan sistem.

2. Monitoring dan Logging untuk WAF
a. Atur CloudWatch Alarms
    Konfigurasikan CloudWatch alarms untuk memantau metrik-metrik penting seperti request yang diblokir, request yang diizinkan, dan jumlah kecocokan aturan (rule match counts).
    Tetapkan ambang batas (thresholds) untuk menerima notifikasi ketika pola lalu lintas tidak biasa atau jumlah rule match yang tinggi terjadi.

Informasi dari CloudWatch Metrics
    Dengan CloudWatch metrics, Anda dapat melihat berbagai metrik terkait aplikasi web dan ACL.
    Contoh informasi yang dapat dilihat: dari mana (IP, negara, dll) lalu lintas yang tidak sesuai (malformed traffic) berasal.

b. Aktifkan AWS WAF Logging
    Aktifkan AWS WAF logging untuk menangkap informasi detail tentang request web, rule matches, dan tindakan yang diambil.
    Simpan log di bucket Amazon S3.
    Gunakan layanan AWS seperti Amazon Athena atau Amazon QuickSight untuk analisis dan pelaporan yang mendalam.

c. Tinjau Log Secara Berkala
    Tinjau AWS WAF logs secara teratur untuk mengidentifikasi potensi serangan, false positives, atau pola lalu lintas berbahaya yang berkembang.
    Selidiki setiap anomali dalam log dengan segera untuk memastikan ancaman baru terdeteksi dan dimitigasi tepat waktu.

3. Memperbarui dan Menyesuaikan Aturan WAF Secara Teratur
a. Tetap Terinformasi (Stay Informed)
    Tetap perbarui dengan ancaman keamanan dan kerentanan terbaru yang relevan dengan tumpukan aplikasi (application stack).
    AWS menyediakan buletin keamanan (security bulletins) dan pembaruan; berlanggananlah untuk tetap mengetahui vektor serangan baru.

b. Uji Perubahan Aturan (Test Rule Changes)
    Sebelum menerapkan perubahan aturan ke produksi, uji di lingkungan staging untuk memastikan tidak secara tidak sengaja memblokir lalu lintas yang sah.
    Gunakan alat seperti web ACL simulator dari AWS WAF untuk memahami dampak perubahan aturan terhadap lalu lintas.

c. Jadwalkan Tinjauan Berkala
    Jadwalkan tinjauan konfigurasi AWS WAF secara teratur, setidaknya setiap tiga bulan (quartal), untuk menilai efektivitasnya terhadap ancaman saat ini.
    Perbarui aturan, kondisi, dan web ACL berdasarkan wawasan yang diperoleh dari monitoring, logging, dan threat intelligence yang sedang berlangsung.

4. Hasil yang Diharapkan dengan Menerapkan Praktik Terbaik Ini
    Anggota blue team dapat mempertahankan postur keamanan yang kuat.
    AWS WAF dioptimalkan untuk melindungi terhadap ancaman.
    Lalu lintas yang sah tetap dapat mengalir dengan lancar ke aplikasi web.
