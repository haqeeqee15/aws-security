Understanding Threat Intelligence in GuardDuty

Sources of Threat Intelligence
GuardDuty integrates data from multiple sources to provide comprehensive threat intelligence, including:

AWS CloudTrail Logs : GuardDuty analyzes CloudTrail logs, identifying patterns of API calls and user activities. This data is crucial for detecting unauthorized access and changes in your AWS environment.

Amazon VPC Flow Logs : By examining VPC Flow Logs, GuardDuty monitors network traffic, enabling the detection of unusual communication patterns and potential security threats.

DNS Logs : GuardDuty analyzes DNS query logs, allowing it to identify connections to malicious domains and detect phishing attempts.

External Threat Feeds : AWS GuardDuty incorporates data from various external threat feeds, enriching the analysis with global threat intelligence. This integration ensures that GuardDuty is updated with the latest information on known threats.


Types of Threats Detected
GuardDuty is capable of identifying a wide range of threats, including but not limited to the ones below.

Unauthorized Access : GuardDuty detects unauthorized attempts to access your AWS resources, such as unusual login activities or suspicious API calls.

Cryptocurrency Mining : GuardDuty can identify instances that are compromised and used for cryptocurrency mining activities, leading to increased costs and reduced performance.

Data Exfiltration : GuardDuty monitors data transfer patterns and identifies potential data exfiltration attempts, helping to prevent sensitive information from being leaked.

Malware and Trojan Activity : GuardDuty detects instances communicating with known malware or command-and-control servers, indicating potential infections.

Brute Force Attacks : GuardDuty identifies repeated login attempts, helping to detect brute force attacks aimed at gaining unauthorized access.

Severity Levels and Alerts
GuardDuty classifies findings into different severity levels, allowing for a prioritized response approach.

Low Severity : Low severity findings indicate potentially suspicious activities that might not be urgent but should be investigated to rule out any security threats.

Medium Severity : Medium severity findings suggest more suspicious activities, requiring prompt investigation as they could indicate ongoing security incidents.

High Severity : High-severity findings signify critical security threats that require immediate attention and remediation to prevent significant damage or data breaches.

Alerts and Notifications : GuardDuty generates alerts for each finding, providing detailed information about the threat. These alerts can be integrated with Amazon CloudWatch Events, allowing for automated responses and notifications to relevant stakeholders via SNS (Simple Notification Service) or other communication channels.

1. Sumber Threat Intelligence (Sources of Threat Intelligence)
GuardDuty mengintegrasikan data dari berbagai sumber untuk menyediakan threat intelligence yang komprehensif.

a. AWS CloudTrail Logs
    Menganalisis CloudTrail logs untuk mengidentifikasi pola panggilan API dan aktivitas pengguna.
    Data ini penting untuk mendeteksi akses tidak sah dan perubahan di lingkungan AWS.

b. Amazon VPC Flow Logs
    Memeriksa VPC Flow Logs untuk memantau lalu lintas jaringan.
    Memungkinkan deteksi pola komunikasi yang tidak biasa dan potensi ancaman keamanan.

c. DNS Logs
    Menganalisis DNS query logs untuk mengidentifikasi koneksi ke domain berbahaya.
    Mendeteksi upaya phishing.

d. External Threat Feeds
    Memasukkan data dari berbagai umpan ancaman eksternal.
    Memperkaya analisis dengan threat intelligence global.
    Integrasi ini memastikan GuardDuty diperbarui dengan informasi terbaru tentang ancaman yang dikenal.

2. Jenis Ancaman yang Terdeteksi (Types of Threats Detected)
GuardDuty mampu mengidentifikasi berbagai ancaman, termasuk tetapi tidak terbatas pada yang disebutkan di bawah ini.

a. Unauthorized Access
    Mendeteksi upaya akses tidak sah ke sumber daya AWS, seperti aktivitas login tidak biasa atau panggilan API mencurigakan.

b. Cryptocurrency Mining
    Mengidentifikasi instance yang dikompromikan dan digunakan untuk aktivitas penambangan cryptocurrency. Dampak: peningkatan biaya dan penurunan performa.

c. Data Exfiltration
    Memantau pola transfer data dan mengidentifikasi potensi upaya eksfiltrasi data. Membantu mencegah kebocoran informasi sensitif.

d. Malware and Trojan Activity
    Mendeteksi instance yang berkomunikasi dengan server malware atau command-and-control (C2) yang dikenal, mengindikasikan potensi infeksi.

e. Brute Force Attacks
    Mengidentifikasi upaya login berulang, membantu mendeteksi serangan brute force yang bertujuan mendapatkan akses tidak sah.

3. Tingkat Keparahan dan Alert (Severity Levels and Alerts)
GuardDuty mengklasifikasikan temuan (findings) ke dalam tingkat keparahan yang berbeda untuk memungkinkan pendekatan respons yang diprioritaskan.

a. Low Severity
    Menunjukkan aktivitas yang berpotensi mencurigakan tetapi mungkin tidak mendesak.
    Harus diselidiki untuk mengesampingkan ancaman keamanan.

b. Medium Severity
    Menunjukkan aktivitas yang lebih mencurigakan.
    Memerlukan investigasi segera karena dapat mengindikasikan insiden keamanan yang sedang berlangsung.

c. High Severity
    Menunjukkan ancaman keamanan kritis.
    Memerlukan perhatian dan perbaikan segera untuk mencegah kerusakan signifikan atau kebocoran data.

d. Alerts and Notifications
    GuardDuty menghasilkan alert untuk setiap temuan, menyediakan informasi detail tentang ancaman.
    Alert ini dapat diintegrasikan dengan Amazon CloudWatch Events, memungkinkan respons otomatis.
    Notifikasi ke pemangku kepentingan relevan melalui SNS (Simple Notification Service) atau saluran komunikasi lainnya.
