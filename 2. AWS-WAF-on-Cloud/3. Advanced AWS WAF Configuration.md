Creating Custom Rules for Specific Applications

When it comes to protecting specific applications, custom rules in AWS WAF are invaluable. They allow you to tailor security measures according to the unique vulnerabilities of your applications. Here's how you can create custom rules:

1. Login to AWS Management Console :
    Go to AWS WAF & Shield.
    Choose the web ACL where you want to add the custom rule.

2. Create a Custom Rule:
    Select "Rules" from the navigation pane.
    Click on "Create rule."
    Define your conditions. For instance, you can base rules on specific query parameters or request headers associated with your application.
    Specify actions for requests that match the conditions. Common actions include allowing, blocking, or counting requests.

3. Implementing Rate-Based Rules:
Rate-based rules are essential for mitigating brute-force attacks or limiting requests from specific IP addresses. Here’s how to set up rate-based rules:
    Within the AWS WAF console, go to the web ACL you want to configure.
    Select "Rate-based rules" from the left panel.
    Create a new rate-based rule.
    Define the rate limit (requests per minute) and the conditions that trigger the rule.
    Choose the action to be taken when the rate limit is exceeded, such as blocking the requests.

Utilizing Regular Expressions for Complex Matching Patterns

AWS WAF supports regular expressions for complex pattern matching. For instance, if you want to block SQL injection attempts, you can use a regular expression to match SQL keywords. Here’s how you can use regex in a custom rule:
    While creating a custom rule, select " Regex pattern set " as the type of condition.
    Define your regular expression pattern. For SQL injection, it could be something like: `.*(SELECT|INSERT|UPDATE|DELETE).*`.
    Choose the action to be taken when the pattern is matched (usually block or count).


Working with IP Sets to Block or Allow Specific IP Addresses

IP sets are powerful for allowing or blocking traffic from specific IP addresses or ranges. Here’s how you can work with IP sets:
    In the AWS WAF console, go to IP Sets.
    Create a new IP set.
    Define the IP addresses or ranges you want to include in the set.
    Use this IP set in your web ACL rules to either allow or block traffic from these addresses.


By combining custom rules, rate-based rules, regex pattern matching, and IP sets, you can create a robust defense mechanism for your applications, ensuring that only legitimate traffic is allowed while malicious attempts are effectively blocked.

1. Custom Rules dan Rate-Based Rules

a. Membuat Custom Rules untuk Aplikasi Spesifik
Custom rules di AWS WAF sangat berharga untuk melindungi aplikasi spesifik karena memungkinkan penyesuaian tindakan keamanan sesuai dengan kerentanan unik aplikasi.
Langkah-langkah membuat custom rule:
    Login ke AWS Management Console, buka AWS WAF & Shield, pilih web ACL tempat Anda ingin menambahkan custom rule.
    Pilih "Rules" dari panel navigasi, klik "Create rule".
    Definisikan kondisi (conditions). Contoh: aturan dapat didasarkan pada parameter query spesifik atau request headers yang terkait dengan aplikasi Anda.
    Tentukan tindakan untuk request yang cocok dengan kondisi (allow, block, atau count).

b. Mengimplementasikan Rate-Based Rules
Rate-based rules penting untuk memitigasi serangan brute-force atau membatasi request dari alamat IP tertentu.

Langkah-langkah menyiapkan rate-based rules:
    Di AWS WAF console, buka web ACL yang ingin dikonfigurasi.
    Pilih "Rate-based rules" dari panel kiri.
    Buat rate-based rule baru.
    Definisikan rate limit (jumlah request per menit) dan kondisi yang memicu rule.
    Pilih tindakan yang akan diambil ketika rate limit terlampaui (contoh: memblokir request).

2. Contoh Dunia Nyata 1: Rate-Based Rules untuk Mencegah Brute Force Attacks

Deskripsi Serangan:
    Brute force attack adalah serangan di mana penyerang mencoba banyak password dengan harapan akhirnya menebak yang benar.

Perlindungan AWS WAF:
    Atur rate-based rules untuk membatasi jumlah percobaan login dari alamat IP tertentu dalam jangka waktu tertentu.
    Gunakan CAPTCHA challenges bersama dengan rate-based rules untuk membedakan antara pengguna manusia dan bot otomatis.
    Pantau pola login dan tetapkan ambang batas (thresholds) yang tepat untuk rate-based rules guna mencegah penguncian akun karena perilaku pengguna sah.

Ilustrasi dari materi:
    Contoh screenshot perilaku pengguna normal.
    Setelah membuat 100+ request dari alamat IP yang sama, ACL akan memunculkan CAPTCHA.

Kesimpulan contoh:
Dengan menerapkan strategi ini di AWS WAF, Anda dapat secara signifikan meningkatkan postur keamanan aplikasi web dan melindunginya dari brute force.

3. Contoh Dunia Nyata 2: Guarding Against Denial of Service (DoS) Attacks

Deskripsi Serangan:
    Serangan DoS membanjiri sistem target dengan lalu lintas sehingga sistem menjadi lambat atau tidak responsif.

Perlindungan AWS WAF:
    Implementasikan rate-based rules untuk membatasi jumlah request dari alamat IP tertentu dalam jangka waktu tertentu.
    Untuk tindakannya, dapat dikonfigurasi untuk block requests.

Ilustrasi dari materi:
    Setelah membuat 100+ request dari alamat IP yang sama, ACL akan memblokir dan mengembalikan respons 500 dengan header "You: Blocked".

4. Regex dan IP Set Matching

a. Menggunakan Regular Expressions untuk Pola Pencocokan yang Kompleks
AWS WAF mendukung regular expressions untuk pencocokan pola yang kompleks.
Contoh penggunaan:
Untuk memblokir percobaan SQL injection, gunakan regular expression untuk mencocokkan kata kunci SQL.
Langkah-langkah menggunakan regex dalam custom rule:
    Saat membuat custom rule, pilih "Regex pattern set" sebagai tipe kondisi.
    Definisikan pola regular expression. Contoh untuk SQL injection: .*(SELECT|INSERT|UPDATE|DELETE).*
    Pilih tindakan yang akan diambil ketika pola cocok (biasanya block atau count).

b. Bekerja dengan IP Sets untuk Memblokir atau Mengizinkan Alamat IP Spesifik
IP sets berguna untuk mengizinkan atau memblokir lalu lintas dari alamat IP atau rentang IP tertentu.
Langkah-langkah bekerja dengan IP sets:
    Di AWS WAF console, buka IP Sets.
    Buat IP set baru.
    Definisikan alamat IP atau rentang IP yang ingin dimasukkan dalam set.
    Gunakan IP set ini dalam aturan web ACL untuk mengizinkan atau memblokir lalu lintas dari alamat tersebut.

5. Kesimpulan
Dengan menggabungkan:
    Custom rules
    Rate-based rules
    Regex pattern matching
    IP sets

Anda dapat menciptakan mekanisme pertahanan yang kuat untuk aplikasi, memastikan hanya lalu lintas yang sah yang diizinkan sementara upaya berbahaya diblokir secara efektif.
