Basic Concepts of AWS WAF

Understanding Web ACLs (Access Control Lists)
AWS WAF (Web Application Firewall) ACL (Access Control List) is a powerful security feature offered by Amazon Web Services, designed to protect your web applications from various online threats. By creating a Web ACL, you can define specific rules and conditions about IP addresses, geolocation, or specific patterns within the incoming requests to allow or block incoming traffic to your web application. AWS WAF ACL acts as a shield, filtering out malicious traffic and ensuring that only legitimate users can access your web resources. It provides a robust defense mechanism, allowing you to safeguard your applications from common web attacks such as SQL injection, cross-site scripting, and DDoS attacks.


A Web ACL consists of two main components:
Rules : Rules are conditions that you define to allow, block, or count web requests. These rules can be based on various criteria such as IP addresses, request headers, query strings, and more.

Rule Action : The action associated with a rule determines what happens when a request matches the rule's conditions. Actions can include allowing the request, blocking it, or counting it (which means you're collecting data about the request without taking any action).

To Create a Web ACL
    Log in to the AWS Management Console and access the AWS WAF console by visiting https://console.aws.amazon.com/wafv2/ .
    In the menu, go to Web ACLs and select the Create a new Web ACL option.
    Specify a Name for the web ACL to uniquely identify it.

Rule Sets: Pre-configured Sets of Rules to Simplify the Process
Rule sets are predefined collections of rules provided by AWS WAF, simplifying the process of setting up security rules for your web applications. These rule sets are created and maintained by AWS security experts and cover common vulnerabilities and threats, such as SQL injection and XSS attacks.


By using managed rule sets, you can quickly apply a set of rules that are known to be effective against specific types of attacks, without having to manually define each rule. This simplifies the setup process and ensures that your applications are protected against common threats right from the start.

1. Choose a Managed Rule Set :
    In the AWS WAF console, go to the Web ACLs section.
    Create a new Web ACL or edit an existing one.
    In the Web ACL editor, add a new rule group. You can choose either a regular rule group or a managed rule group.
    Select "Managed rule group" and choose from the available rule sets provided by AWS. These rule sets cover various types of threats such as SQL injection, XSS attacks, and more.


2. Select the Appropriate Rule Set :
    Depending on your application and its vulnerabilities, select the relevant rule set. For example, if you're concerned about SQL injection attacks, choose the “SQL Injection” managed rule set.

Conditions and Rules: How to Define Conditions and Rules for Web Requests

Conditions : Conditions are the building blocks of rules that define the characteristics of web requests you want to match. These can include IP addresses, strings in the request, request headers, query strings, and more. For example, you can create a condition to match requests coming from a specific IP address range.

Rules : Rules are composed of one or more conditions. You define rules based on these conditions to specify what action AWS WAF should take when a web request matches the defined conditions. For instance, you could create a rule that blocks all requests containing a specific SQL injection pattern in the query string.

When creating rules, it's crucial to consider the specific security requirements of your application. You can create custom rules tailored to your application's needs, or you can use a combination of custom rules and managed rule sets to achieve comprehensive security coverage.

Steps to Creating an AWS WAF ACL

Sign in to AWS Console: Log in to the AWS Management Console using your credentials.
Access AWS WAF Console : Go to the AWS WAF console by visiting https://console.aws.amazon.com/wafv2/ .
Create a Web ACL : In the AWS WAF console, go to Web ACLs in the navigation pane, and select "Create web ACL."
Specify ACL Details : Enter a unique and descriptive name for your Web ACL. This name will help you identify and manage the ACL easily.
Configure Rules : Define rules for your Web ACL based on your security requirements. You can create rules to block specific IP addresses, filter requests based on geolocation, or detect patterns indicative of attacks.
Add Conditions : Set conditions for the rules, specifying when they should be triggered. Conditions can be based on various factors such as IP addresses, query strings, or request headers.

1. Pengertian Web ACL (Access Control Lists)
    AWS WAF ACL adalah fitur keamanan untuk melindungi aplikasi web dari berbagai ancaman online.
    Dengan Web ACL, Anda dapat mendefinisikan aturan dan kondisi spesifik tentang alamat IP, geolokasi, atau pola spesifik dalam request yang masuk.
    Tujuannya: mengizinkan atau memblokir lalu lintas yang masuk ke aplikasi web.
    Web ACL bertindak sebagai perisai (shield) untuk menyaring lalu lintas berbahaya dan memastikan hanya pengguna sah yang dapat mengakses sumber daya web.
    Memberikan mekanisme pertahanan yang kuat terhadap serangan web umum: SQL injection, XSS, DDoS.

2. Dua Komponen Utama Web ACL
a. Rules
    Kondisi yang Anda definisikan untuk mengizinkan (allow), memblokir (block), atau menghitung (count) request web.
    Dapat didasarkan pada berbagai kriteria: alamat IP, request headers, query strings, dll.

b. Rule Action
    Tindakan yang terkait dengan aturan, ditentukan ketika request cocok dengan kondisi aturan.
    Allow → mengizinkan request.
    Block → memblokir request.
    Count → mengumpulkan data tentang request tanpa mengambil tindakan.

3. Cara Membuat Web ACL
    Login ke AWS Management Console.
    Akses AWS WAF console melalui https://console.aws.amazon.com/wafv2/.
    Buka menu Web ACLs dan pilih Create a new Web ACL.
    Tentukan Name untuk web ACL (sebagai identifikasi unik).

4. Rule Sets: Kumpulan Aturan yang Dikonfigurasi Sebelumnya
Definisi
    Rule sets adalah kumpulan aturan yang telah ditentukan sebelumnya (predefined) yang disediakan oleh AWS WAF.
    Dibuat dan dikelola oleh ahli keamanan AWS.
    Mencakup kerentanan dan ancaman umum: SQL injection, XSS, dll.

Manfaat
    Mempercepat penyiapan aturan keamanan untuk aplikasi web.
    Tidak perlu mendefinisikan setiap aturan secara manual.
    Memastikan aplikasi terlindungi dari ancaman umum sejak awal.

Langkah Menggunakan Managed Rule Set
    Di AWS WAF console, buka bagian Web ACLs.
    Buat Web ACL baru atau edit yang sudah ada.
    Di Web ACL editor, tambahkan rule group baru.
    Pilih Managed rule group dan pilih dari rule set yang tersedia (SQL injection, XSS, dll).

5. Conditions dan Rules
Conditions (Kondisi)
    Blok pembangun dari rules.
    Mendefinisikan karakteristik request web yang ingin dicocokkan.
    Dapat berupa: alamat IP, string dalam request, request headers, query strings, dll.
    Contoh: kondisi untuk mencocokkan request yang berasal dari rentang alamat IP tertentu.

Rules (Aturan)
    Terdiri dari satu atau lebih conditions.
    Menentukan tindakan apa yang harus diambil AWS WAF ketika request web cocok dengan kondisi yang didefinisikan.
    Contoh: aturan yang memblokir semua request yang mengandung pola SQL injection tertentu dalam query string.

Catatan Penting
    Saat membuat rules, pertimbangkan persyaratan keamanan spesifik aplikasi.
    Anda dapat membuat aturan kustom yang disesuaikan dengan kebutuhan aplikasi.
    Dapat juga menggunakan kombinasi aturan kustom dan managed rule sets untuk mencapai cakupan keamanan yang komprehensif.

6. Langkah-Langkah Membuat AWS WAF ACL (Ringkasan)
    Sign in to AWS Console → Login ke AWS Management Console.
    Access AWS WAF Console → Buka https://console.aws.amazon.com/wafv2/.
    Create a Web ACL → Di navigasi pane, buka Web ACLs, pilih "Create web ACL".
    Specify ACL Details → Masukkan nama yang unik dan deskriptif untuk Web ACL.
    Configure Rules → Definisikan aturan berdasarkan persyaratan keamanan (blok IP, filter berdasarkan geolokasi, deteksi pola serangan).
    Add Conditions → Tetapkan kondisi untuk rules, menentukan kapan aturan harus dipicu (berdasarkan alamat IP, query strings, request headers, dll).
