Introduction to AWS GuardDuty

AWS GuardDuty is a fully managed threat detection service offered by Amazon Web Services. It is designed to protect your AWS environment by continuously monitoring for malicious activities and unauthorized behavior. By analyzing billions of events across multiple AWS data sources, GuardDuty identifies security threats, such as unusual API calls, potentially compromised instances, and unauthorized access, providing you with actionable intelligence to remediate security issues proactively.


We will explore Amazon Web Services' GuardDuty service in-depth, focusing on empowering blue teams to effectively detect, respond to, and mitigate security threats within their AWS environments.

1. Definisi AWS GuardDuty
    AWS GuardDuty adalah layanan deteksi ancaman (threat detection service) yang dikelola sepenuhnya (fully managed) oleh Amazon Web Services.
    Dirancang untuk melindungi lingkungan AWS dengan cara memantau secara terus-menerus (continuous monitoring) terhadap aktivitas berbahaya dan perilaku tidak sah.

2. Cara Kerja GuardDuty
    Menganalisis miliaran peristiwa (billions of events) dari berbagai sumber data AWS (multiple AWS data sources).
    Mengidentifikasi ancaman keamanan seperti:
        Panggilan API yang tidak biasa (unusual API calls)
        Instance yang berpotensi dikompromikan (potentially compromised instances)
        Akses tidak sah (unauthorized access)

3. Output yang Diberikan
    Memberikan intelijen yang dapat ditindaklanjuti (actionable intelligence) untuk memperbaiki masalah keamanan secara proaktif (remediate security issues proactively).

4. Tujuan Eksplorasi dalam Kursus
    Mempelajari layanan AWS GuardDuty secara mendalam (in-depth).
    Fokus pada pemberdayaan blue teams agar mampu:
        Mendeteksi (detect)
        Merespons (respond to)
        Memitigasi (mitigate) ancaman keamanan
dalam lingkungan AWS mereka secara efektif.
