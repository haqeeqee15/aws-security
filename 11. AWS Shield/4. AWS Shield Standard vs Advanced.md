AWS Shield Standard vs Advanced

Automatic Protection for All AWS Customers
AWS Shield Standard, an integral component of AWS's security ecosystem, offers automatic protection to all AWS customers without additional charges. Tailored to counter common and frequent Distributed Denial of Service (DDoS) attacks targeting websites and applications, it ensures robust defense against prevalent network and transport layer threats.

Comprehensive Defense with CloudFront and Route 53
Combining AWS Shield Standard with Amazon CloudFront, Amazon Route 53, Elastic Load Balancer (ELB), and Application Load Balancer (ALB) provides users with comprehensive availability protection against all known infrastructure attacks (Layers 3 and 4). This integrated approach enhances security, safeguarding digital assets from a broad spectrum of threats.

Static Threshold DDoS Protection
AWS Shield Standard continuously monitors network traffic, employing traffic signatures, anomaly detection algorithms, and advanced analysis techniques to detect malicious traffic in real-time. While it sets static thresholds for various AWS resource types, it does not offer custom protections tailored to specific applications.

Inline Attack Mitigation: Real-Time Defense
Automated mitigation techniques integrated into AWS services provide proactive protection against common infrastructure attacks in real-time. Techniques such as deterministic packet filtering and priority-based traffic shaping ensure resilience and availability without introducing latency.

AWS Shield Advanced
Expanded Defense Coverage & Cost Protection
For organizations seeking enhanced security, AWS Shield Advanced goes beyond basic protections. It uses advanced automatic mitigations against attacks targeting EC2, ELB, CloudFront, Global Accelerator, and Route 53 resources. Shield Advanced not only safeguards against service downtime but also provides cost protection for scaling during a DDoS attack.

Tailored Detection Based on Traffic Patterns
Shield Advanced offers customized detection based on traffic patterns, enabling the identification of smaller-scale DDoS attacks and application layer threats in real-time.

Access to the AWS Shield Response Team (SRT)
Customers with Business or Enterprise support plans gain 24/7 access to the Shield Response Team (SRT), providing expertise in incident triage, root cause identification, and mitigation application.

Application Layer DDoS Mitigation & Integration with AWS WAF
Shield Advanced offers automated protection against application layer (L7) DDoS events and integrates with AWS WAF for an extra layer of security, enhancing DDoS mitigation efforts.

Historic and Real-Time Attack Log Availability for Incident Analysis
Access to historic and real-time attack logs ensures comprehensive incident analysis, aiding in the identification of attack trends and patterns over time.

Centralized Protection Management
AWS Shield Advanced customers can use AWS Firewall Manager to implement protections across the entire organization, ensuring consistent application security.

Conclusion
The choice between AWS Shield Standard and Shield Advanced depends on an organization's specific security needs and risk profiles. Shield Standard is a cost-effective choice for most businesses, offering essential protection against common DDoS attacks. Shield Advanced is suitable for critical applications requiring advanced, tailored, and real-time DDoS protection. 

1. AWS Shield Standard
a. Automatic Protection for All AWS Customers
    Shield Standard adalah komponen integral dari ekosistem keamanan AWS.
    Memberikan perlindungan otomatis kepada semua pelanggan AWS tanpa biaya tambahan
    Dirancang untuk melawan serangan DDoS yang umum dan sering terjadi yang menargetkan website dan aplikasi.
    Memastikan pertahanan yang kuat terhadap ancaman umum di network dan transport layer.

b. Comprehensive Defense dengan CloudFront dan Route 53
    Menggabungkan Shield Standard dengan Amazon CloudFront, Amazon Route 53, Elastic Load Balancer (ELB), dan Application Load Balancer (ALB) memberikan perlindungan ketersediaan komprehensif terhadap semua serangan infrastruktur yang diketahui (Layer 3 dan 4).
    Pendekatan terintegrasi ini meningkatkan keamanan dan melindungi aset digital dari berbagai ancaman.

c. Static Threshold DDoS Protection
    Shield Standard secara terus menerus memonitor lalu lintas jaringan.
    Menggunakan traffic signatures, anomaly detection algorithms, dan teknik analisis lanjutan untuk mendeteksi lalu lintas berbahaya secara real-time.
    Menetapkan static thresholds (ambang batas statis) untuk berbagai tipe resource AWS.
    Tidak menawarkan custom protections yang disesuaikan dengan aplikasi spesifik.

d. Inline Attack Mitigation – Real-Time Defense
    Teknik mitigasi otomatis yang diintegrasikan ke dalam layanan AWS memberikan perlindungan proaktif terhadap serangan infrastruktur umum secara real-time.
    Teknik seperti deterministic packet filtering dan priority-based traffic shaping memastikan ketahanan dan ketersediaan tanpa menimbulkan latensi.

2. AWS Shield Advanced
a. Expanded Defense Coverage & Cost Protection
    Untuk organisasi yang mencari keamanan yang ditingkatkan.
    Menggunakan advanced automatic mitigations terhadap serangan yang menargetkan resource EC2, ELB, CloudFront, Global Accelerator, dan Route 53.
    Tidak hanya melindungi dari downtime layanan tetapi juga memberikan cost protection untuk scaling selama serangan DDoS.

b. Tailored Detection Based on Traffic Patterns
    Menawarkan deteksi yang disesuaikan (customized detection) berdasarkan pola lalu lintas.
    Memungkinkan identifikasi serangan DDoS skala kecil dan ancaman application layer secara real-time.

c. Access to the AWS Shield Response Team (SRT)
    Pelanggan dengan Business atau Enterprise support plans mendapatkan akses 24/7 ke Shield Response Team (SRT).
    Memberikan keahlian dalam incident triage, identifikasi akar penyebab, dan penerapan mitigasi.

d. Application Layer DDoS Mitigation & Integration with AWS WAF
    Menawarkan perlindungan otomatis terhadap DDoS events di application layer (L7).
    Terintegrasi dengan AWS WAF untuk lapisan keamanan tambahan, meningkatkan upaya mitigasi DDoS.

e. Historic and Real-Time Attack Log Availability for Incident Analysis
    Akses ke log serangan historis dan real-time memastikan analisis insiden yang komprehensif.
    Membantu mengidentifikasi tren serangan dan pola dari waktu ke waktu.

f. Centralized Protection Management
    Pelanggan Shield Advanced dapat menggunakan AWS Firewall Manager untuk menerapkan perlindungan di seluruh organisasi.
    Memastikan keamanan aplikasi yang konsisten.

3. Kesimpulan
Pilihan antara Shield Standard dan Shield Advanced tergantung pada kebutuhan keamanan spesifik dan profil risiko organisasi.
Shield Standard:
    Pilihan yang cost-effective untuk sebagian besar bisnis.
    Menawarkan perlindungan esensial terhadap serangan DDoS umum.

Shield Advanced:
    Cocok untuk aplikasi kritis yang memerlukan perlindungan DDoS yang advanced, tailored, dan real-time.
