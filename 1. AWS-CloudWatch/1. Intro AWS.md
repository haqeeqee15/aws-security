Introduction to AWS

AWS, or Amazon Web Services, is a comprehensive and widely-used cloud computing platform provided by Amazon.com. It offers a variety of cloud services, including computing power, storage options, networking, databases, machine learning, analytics, and more, all delivered over the internet.


Here are some key aspects of AWS:


1. Compute Services:
    Amazon EC2 (Elastic Compute Cloud): Provides scalable virtual servers in the cloud.
    AWS Lambda: Allows you to run code without provisioning or managing servers, following the serverless computing model.

2. Storage and Databases:    
    Amazon S3 (Simple Storage Service): Object storage service offering scalable storage for files, images, and data.
    Amazon RDS (Relational Database Service): Managed relational database service supporting various database engines like MySQL, PostgreSQL, and SQL Server.
    Amazon DynamoDB: NoSQL database service for applications that need seamless and predictable performance at any scale.

3. Networking:    
    Amazon VPC (Virtual Private Cloud): Lets you create isolated networks within the AWS cloud.
    Amazon Route 53: A scalable Domain Name System (DNS) web service designed to route end-user requests to endpoints.

4. Developer Tools:    
    AWS CodeDeploy: Automates code deployments to any instance.
    AWS CodePipeline: Helps you automate your software release process.

5. AI and Machine Learning:    
    Amazon SageMaker: A fully managed service that enables developers to build, train, and deploy machine learning models.
    Amazon Polly: Text-to-speech service that uses deep learning technologies to synthesize speech that sounds like a natural human voice.

6. Analytics:    
    Amazon Redshift: Fully managed, petabyte-scale data warehouse service in the cloud.
    Amazon QuickSight: Business analytics service to build visualizations, perform ad-hoc analysis, and get insights from diverse datasets.

7. Security and Identity:    
    AWS Identity and Access Management (IAM): Allows you to manage access to AWS services and resources securely.
    Amazon Inspector: Automated security assessment service to help improve the security and compliance of applications deployed on AWS.

8. Internet of Things (IoT):    
    AWS IoT Core: Managed cloud service that lets connected devices interact easily and securely with cloud applications and other devices.

9. Content Delivery and CDN:    
    Amazon CloudFront: Content delivery network (CDN) service that securely delivers data, videos, applications, and APIs to customers globally.


AWS provides flexibility, scalability, and cost-effectiveness for businesses of all sizes. It's widely used by startups, enterprises, and individuals for various purposes, including hosting websites, running applications, storing data, and leveraging advanced technologies like machine learning and big data analytics. AWS also offers a free tier with limited services for users to get started and explore the platform without incurring charges.

Create AWS Account


1. Visit the AWS Website:     
   Go to the AWS official website by typing ‘aws.amazon.com’ in your web browser.

2. Click on "Create an AWS Account":    
   On the AWS homepage, click on the "Create an AWS Account" button. 

3. Sign in to Your Amazon Account:    
   If you already have an Amazon.com account, you can sign in with your existing Amazon credentials. If you don't have an Amazon.com account, you'll need to create one. Follow the prompts to enter your email address and create a password.

4. Provide Account Information:    
   You'll need to provide some basic information, including your contact details and payment information. AWS requires a credit card or debit card to verify your identity, even if you're signing up for the free tier. However, most services within the free tier have limits that are unlikely to incur charges unless you exceed them

5. Choose a Support Plan:    
   AWS offers different support plans. If you're just getting started, you can choose the free support plan. If you need more advanced support options, you can choose one of the paid plans.

6. Verify Your Phone Number:    
   AWS will require you to verify your phone number by either receiving a text message or a phone call with a verification code. Enter the code to verify your phone number.

7. Setup Two-Factor Authentication (Optional but Recommended):    
   Setting up two-factor authentication (2FA) enhances the security of your AWS account. You can set it up during the registration process or after your account is created.

8. Complete the Registration:    
   Once you've provided all the necessary information, your AWS account will be created. You might need to wait a few moments for the account setup to complete.

9.  Access the AWS Management Console:    
   After your account is set up, you can access the AWS Management Console, which is the web-based interface for managing your AWS resources. You can start creating and managing services from here.

Remember to follow AWS's best practices for security, such as not sharing your access credentials, setting up proper permissions, and enabling billing alerts to monitor your usage. Good luck with your AWS learning journey!


1. Definisi AWS
    AWS adalah platform komputasi cloud dari Amazon.com.
    Menyediakan berbagai layanan cloud: komputasi, penyimpanan, jaringan, database, machine learning, analitik, dan lain-lain, semuanya melalui internet.

2. Layanan AWS Berdasarkan Kategori
Compute Services
    Amazon EC2: Server virtual yang bisa diskalakan di cloud.
    AWS Lambda: Menjalankan kode tanpa perlu mengelola server (serverless).

Storage and Databases
    Amazon S3: Penyimpanan objek untuk file, gambar, dan data.
    Amazon RDS: Managed relational database untuk MySQL, PostgreSQL, SQL Server.
    Amazon DynamoDB: Database NoSQL dengan performa yang stabil di segala skala.

Networking
    Amazon VPC: Membangun jaringan terisolasi di cloud AWS.
    Amazon Route 53: Layanan DNS skalabel untuk routing request.

Developer Tools
    AWS CodeDeploy: Otomatisasi deployment kode ke berbagai instance.
    AWS CodePipeline: Otomatisasi proses rilis software.

AI and Machine Learning
    Amazon SageMaker: Build, train, dan deploy model ML secara terkelola.
    Amazon Polly: Text-to-speech dengan suara alami seperti manusia.

Analytics
    Amazon Redshift: Data warehouse terkelola skala petabyte.
    Amazon QuickSight: Business analytics untuk visualisasi dan analisis data.

Security and Identity
    AWS IAM (Identity and Access Management): Mengelola akses ke layanan AWS secara aman.
    Amazon Inspector: Security assessment otomatis untuk aplikasi di AWS.

Internet of Things (IoT)
    AWS IoT Core: Layanan cloud terkelola untuk menghubungkan perangkat IoT dengan aplikasi cloud secara aman.
    
Content Delivery and CDN
    Amazon CloudFront: Layanan CDN untuk mengirim data, video, aplikasi, dan API ke pelanggan secara global.

3. Karakteristik AWS

    Memberikan fleksibilitas, skalabilitas, dan efektivitas biaya.
    Digunakan oleh startup, enterprise, hingga individu.
    Tujuan umum: hosting website, menjalankan aplikasi, penyimpanan data, machine learning, big data analytics.
    Tersedia free tier dengan batasan layanan untuk mencoba platform tanpa biaya.

4. Langkah-Langkah Membuat Akun AWS
    Kunjungi situs resmi AWS (aws.amazon.com).
    Klik tombol "Create an AWS Account".
    Sign in dengan akun Amazon yang sudah ada, atau buat akun Amazon baru.
    Masukkan informasi kontak dan data pembayaran (kartu kredit/debit untuk verifikasi identitas).
    Pilih paket dukungan (support plan) – pilih free plan untuk pemula.
    Verifikasi nomor telepon melalui SMS atau panggilan suara.
    (Opsional namun direkomendasikan) Atur Two-Factor Authentication (2FA).
    Tunggu beberapa saat hingga akun selesai dibuat.
    Akses AWS Management Console untuk mulai mengelola layanan AWS.

5. Praktik Terbaik yang Diingatkan
    Jangan membagikan akses kredensial.
    Atur permission dengan benar.
    Aktifkan billing alerts untuk memantau penggunaan agar tidak terjadi tagihan tak terduga.
